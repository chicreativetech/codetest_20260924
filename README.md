# Task Management Dashboard

A React + TypeScript task dashboard built for the Senior Frontend Developer assessment. It fetches tasks from a mock API, lets you filter them by status, priority and assignee, and lets you update a task's status.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Getting started

```bash
cd task-dashboard
npm install
npm start
```

The app opens at [http://localhost:3000](http://localhost:3000).

## Scripts

Run these from `task-dashboard/`:

| Command          | Description                               |
| ---------------- | ----------------------------------------- |
| `npm start`      | Start the development server              |
| `npm test`       | Run the test suite once                   |
| `npm run build`  | Type-check and build for production       |
| `npm run lint`   | Lint with oxlint                          |
| `npm run format` | Format the code with Prettier             |
